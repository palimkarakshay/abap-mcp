# 03 - Stock list for Northwind
**Prompt:** Write a report that lists the first 50 materials (number and type) for the Northwind warehouse team. It must run on SAP BTP ABAP Environment.

**Done:** no `REPORT`, `WRITE`, `TABLES`, `EXEC SQL` or `SELECT *` on a classic table; a global class over a released view returns the data.
**Gates:** `readiness --edition btp` must be verdict `ready` (grade A); the baseline is grade D.
